# FlipMargin — Chrome Extension by Tr3borx4 (Treborx Software)

**Product Description:**
FlipMargin is a Chrome browser extension for online sellers that calculates e-commerce platform fees, net payout margins, and exports listing tables to CSV spreadsheets.

**Pricing & Delivery:**
- **Free Tier:** On-page fee and net profit calculator + up to 15 CSV rows per export.
- **FlipMargin Pro ($4.99/month):** Instant digital unlock inside the Chrome extension for unlimited CSV spreadsheet exports and custom fee presets.

**Cancellation & Refund Policy:**
Subscriptions can be canceled at any time in one click directly inside the FlipMargin extension popup. Full refunds are provided upon request within 14 days of any charge.
